01 · CONSTRUIR O CONCEITO

Por que dois endereços parecidos não se alcançam?

01

Os hosts 192.168.10.62/26 e 192.168.10.65/26 estão conectados ao mesmo switch. O primeiro pertence ao bloco .0–.63; o segundo, ao bloco .64–.127. Estar no mesmo switch não os coloca automaticamente na mesma sub-rede IP. Sem um caminho de camada 3 adequado, a comunicação entre essas redes não funciona.

A máscara participa da decisão de entrega local ou por gateway. O plano precisa combinar sub-rede IP, VLAN, interface de camada 3 e configuração do host. Uma mudança na máscara não cria uma VLAN.
02 · CONSTRUIR O CONCEITO

32 bits: rede e host

02

IPv4 tem 32 bits. Um prefixo /p reserva p bits para identificar a rede e deixa 32−p bits no sufixo. Uma máscara válida tem bits 1 contíguos seguidos de bits 0. Em /26, a máscara é 255.255.255.192; os dois primeiros bits do último octeto pertencem à rede.

O bloco contém 2^(32−p) endereços. Na aritmética convencional para prefixos até /30, subtraem-se dois endereços: o identificador da rede e o broadcast. Nem todo bloco é adequado a uma LAN real. /31 e /32 têm usos particulares e não seguem a mesma interpretação de LAN.
03 · CONSTRUIR O CONCEITO

Exemplo completo: 192.168.10.77/26

03

O bloco /26 tem 64 endereços. No último octeto, os limites são 0, 64, 128 e 192. Como 77 está entre 64 e 127, a rede é 192.168.10.64/26 e o broadcast é 192.168.10.127. A faixa convencional é 192.168.10.65 até 192.168.10.126, com 62 endereços utilizáveis.

Pelo método binário, faça AND entre IP e máscara para obter a rede. Complete os bits de host com 1 para obter o broadcast. O salto 256−192=64 é um atalho válido para esse octeto; em prefixos menores que /24, aplique o método ao octeto significativo correto.
04 · CONSTRUIR O CONCEITO

Quatro sub-redes iguais dentro de um /24

04

Dividir 192.168.10.0/24 em quatro partes iguais exige dois bits adicionais de rede: /26. Os blocos são .0/26, .64/26, .128/26 e .192/26. Cada um tem 64 endereços e, no modelo de LAN convencional, 62 utilizáveis. A soma dos blocos continua sendo os 256 endereços originais.

Um setor com 63 interfaces não cabe num /26. Conte computadores, impressoras, telefones, equipamentos e o gateway. Reserve crescimento de forma explícita. A próxima aula combina blocos diferentes para grupos de tamanhos distintos.
05 · CONSTRUIR O CONCEITO

Validar não é escolher sempre o primeiro IP

05

O gateway pode ser qualquer endereço utilizável adequado ao projeto; .1 ou o primeiro host são convenções, não regras universais. Ele deve estar alcançável no segmento e corresponder à interface de camada 3 correta. Não atribua o ID de rede nem o broadcast a um host numa LAN convencional.

Um /31 pode usar seus dois endereços em um enlace IPv4 ponto a ponto conforme a RFC 3021. Um /32 identifica um único endereço, como uma rota de host; não oferece uma faixa LAN convencional. A calculadora explicita essas exceções. Ela valida aritmética de blocos, não disponibilidade global ou política de uso do endereço.

SIMULADOR · DO BIT AO BLOCO

Divida a rede, um bit de cada vez

Escolha a rede inicial e o prefixo final. Cada bit emprestado dobra o número de sub-redes e reduz pela metade o tamanho de cada bloco.

Desafio: Você tem dois endereços utilizáveis em uma sub-rede /30. O que colocaria nela?
Ver uma resposta

Um enlace ponto a ponto entre dois roteadores: um endereço para cada interface. Se uma interface for o gateway de uma LAN, restará um endereço para outro dispositivo.

Em enlaces ponto a ponto compatíveis, /31 é outra possibilidade específica, prevista na RFC 3021.

Representação esquemática: ao passar por /24 a escala muda, dos blocos /24 de uma rede /16 para os endereços de um /24 escolhido. Uma divisão binária usa limites alinhados; não representa endereços públicos disponíveis para uso.

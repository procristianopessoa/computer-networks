# Aula 07 — Camada de enlace e Ethernet

Página independente e estática, pronta para GitHub Pages ou incorporação no Moodle.

## Conteúdo

- `index.html`: página completa, incluindo CSS e JavaScript sem dependências externas.

## Publicação

Copie a pasta `aula07-enlace-ethernet` para a raiz do repositório de Redes. A URL será:

```text
https://SEU-USUARIO.github.io/SEU-REPOSITORIO/aula07-enlace-ethernet/
```

Para Moodle, use o endereço publicado em um iframe ou em um link para abertura em nova aba.

## Interações incluídas

1. identificação de MAC;
2. dissecação do quadro Ethernet;
3. identificação de topologia;
4. simulador de aprendizagem da tabela MAC/CAM;
5. comparação half/full duplex;
6. flashcards;
7. troubleshooting em camada 1/2;
8. quiz de 15 questões com nota local.

O progresso e a última nota ficam apenas no `localStorage` do navegador do aluno.
